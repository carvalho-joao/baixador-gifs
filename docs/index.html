Baixe GIFs do Twitter / X

Cole o link do post. Você baixa o GIF como MP4 (leve, igual ao original) ou converte para um arquivo .gif de verdade, aqui mesmo no navegador.

Funciona com links de x.com, twitter.com, fxtwitter, vxtwitter ou só o número do post.

1. Copie

No app ou site, toque em compartilhar e em "Copiar link".

2. Cole

Cole aqui. A busca começa sozinha quando o link é reconhecido.

3. Baixe

MP4 para WhatsApp e redes; .gif para onde só aceita GIF.

Tem Android? Use o app

Salva direto na galeria e aparece no menu Compartilhar do app do X.

Baixar APK
Os dados do post vêm da API pública do FxTwitter (api.fxtwitter.com); o vídeo vem direto do servidor do Twitter. Tudo acontece no seu navegador. Só funciona com posts públicos. Respeite os direitos de quem criou o conteúdo. Código no GitHub.
